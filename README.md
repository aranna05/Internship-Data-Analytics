## 📌 About This Repository

This repository is a collection of **5 end-to-end data analytics projects** completed during my **fully sponsored Data Analytics Internship at [Elevvo Pathways](https://www.linkedin.com/company/elevvopaths)**.

Each project tackles a real-world business problem: from **cleaning raw data** and **exploratory analysis** to **forecasting**, **statistical testing**, and **dashboard storytelling**.

> 💡 **Goal:** Turn raw, messy data into clear, actionable insights.

## 🔍 Project Details

<details>
<summary><b>🚢 1. Titanic: Survival Analysis</b></summary>
<br/>

**Objective:** Explore the Titanic dataset to uncover which factors influenced passenger survival.

- Handled missing values (Age, Cabin, Embarked)
- Analyzed survival by gender, class, age group, and fare
- Built clear visualizations to highlight key patterns

**Skills:** `EDA` · `Data Visualization` · `Feature Analysis`

</details>

<details>
<summary><b>🧹 2. Generation-wise Data Cleaning (2017–2021)</b></summary>
<br/>

**Objective:** Clean and standardize multi-year, generation-wise data to make it analysis-ready.

- Removed duplicates and inconsistencies
- Fixed data types, formats, and missing values
- Merged and structured data across years (2017–2021)

**Skills:** `Data Cleaning` · `Preprocessing` · `Data Wrangling`

</details>

<details>
<summary><b>🛒 3. Walmart Sales Forecast</b></summary>
<br/>

**Objective:** Forecast future sales using historical Walmart data.

- Explored trends, seasonality, and holiday impact
- Engineered time-based features
- Built and evaluated forecasting models

**Skills:** `Time Series` · `Forecasting` · `Feature Engineering` · `Model Evaluation`

</details>

<details>
<summary><b>📣 4. Marketing A/B Testing</b></summary>
<br/>

**Objective:** Measure whether a marketing campaign variant performs better than the control group.

- Compared conversion rates between test groups
- Applied statistical hypothesis testing
- Translated results into clear business recommendations

**Skills:** `A/B Testing` · `Hypothesis Testing` · `Statistical Analysis`

</details>

<details>
<summary><b>📊 5. Superstore Sales Dashboard</b></summary>
<br/>

**Objective:** Build an interactive dashboard to monitor sales performance and profitability.

- Tracked sales, profit, and category-wise performance
- Identified top-performing regions and products
- Designed a clean, decision-friendly layout

**Skills:** `Dashboard Design` · `KPI Tracking` · `Business Intelligence`

</details>

## 🚀 Getting Started

```bash
# 1️⃣ Clone the repository
git clone https://github.com/aranna05/Internship-Data-Analytics.git

# 2️⃣ Move into the project folder
cd Internship-Data-Analytics

# 3️⃣ Install the required libraries
pip install pandas numpy matplotlib seaborn scikit-learn scipy statsmodels jupyter

# 4️⃣ Launch Jupyter Notebook
jupyter notebook
```

Then open any project folder and run the notebook to reproduce the analysis. ✨
